# Colour palette options (for Ben to choose)

Status: **options only. Ben chooses.** Nothing is changed in the app yet.

## How to read this

- **Contrast with the page** (warm paper `#fdfcf8`): text needs at least 4.5 to 1 to be easy to read. Borders and block edges need 3 to 1.
- **Contrast with the ink** (`#1d1d1f`): tells which colors can carry dark text inside a block.
- A color that passes 4.5 on the page can hold text on its own. A light color (contrast 3 or lower on the page) should be used only as a fill, with dark text on it.

## Suggested use (if you agree)

- **Groups on My calendar:** one fill per group, from the light colors, with dark text. For example: Urgent Clay, Significant Apricot, Not urgent Sky, Can wait Sage, Later Lavender. Check that the group names are still readable.
- **Buttons and headings:** Moss (current) or Ocean.
- **Warnings:** none in red. A calm accent such as Rose for a neutral note, never for failure.
