# Manual checks

Steps for a person to try in a browser. Each feature adds its own section here.

## Setup check (2026-11-16)

1. Run `npm start` in the project folder. It prints an address (http://localhost:3000).
2. Open that address in Chrome.
3. You should see the heading "Focus app" and the line "Setup complete. The study tools will appear here."
4. Make the browser window narrow, about phone width. The text should still fit with no sideways scrolling.
5. Press Tab. Nothing should break. (There are no buttons yet.)
